Otium portability gaps

Runnable examples are organized by subject under examples/, with no C/Chez
subdirectories. Launchers select the runtime. The native extension fixture
belongs in c/tests/modules/, beside the C ABI test. README contents were not
edited when examples moved.

Verified common surface

make test-library runs the same library and module checks, OTCL acceptance,
the reload demo, both multimethod examples, and the completed hand exercises
on both runtimes. The library checks also run under C GC stress. Root make
test includes this target alongside the shared reader, expander, CLI,
conditions, help, and REPL suites. FFI and SDL retain their focused targets.

Both runtimes load shared/prelude/core.scm. Collection helpers, dotimes,
strings/buffers, callable collections and keywords, copying put, common
condition values, clocks, and read-file now have a common API. The optional
otium.extra module contains threading macros, partial, comp, group-by, and
frequencies. defn was removed; use def with a procedure head.

Both require spellings are accepted. Module search checks .ot then .scm in
each path directory. The shared reload example preserves array state with
defonce and uses a forwarding function, which follows redefinition on both.
Saved function values still keep their old implementation on both runtimes.

OTCL is now one implementation in examples/otcl/. Its acceptance tests live
in shared/tests/otcl.scm. Tcl-facing division explicitly chooses quotient for
exact integer results and inexact division for fractions. There is no second
interpreter maintained for Chez.

Remaining intentional differences

- Chez retains its numeric tower, arbitrary-size exact integers, ratios,
  complex numbers, and native continuations. C retains its bounded numeric
  representations, embedding API, and collector controls.
- Host Scheme facilities are available through (require chez) and chez/
  names. They are not portable Otium library dependencies.
- Native exception wording, runtime debugging, and implementation-specific
  printing remain different. General numeric formatting is not guaranteed
  identical beyond the tested common cases.
- C case conversion is ASCII-oriented; native Chez case conversion follows
  Unicode. Avoid depending on non-ASCII case conversion in shared code.
- read-file's portable input is valid UTF-8. Invalid-byte decoding and native
  filesystem error diagnostics are not unified. There is no common streaming
  file/port API or directory API yet.
- Reload is non-atomic and retains definitions removed from source. Alias
  retargeting and namespace reflection are outside the common contract.
- Chez's native generic-dispatch identities include host values that do not
  exist on C. Shared examples use common types; this is not a promise that
  native vectors, hashtables, or characters dispatch identically to Otium
  collections on both engines.

Unfinished examples and coverage

examples/hand/lc-2-add-two-numbers.ot is unfinished and contains the 555t
placeholder. It is not a portability fixture. The retired Raylib roguelike's
font atlas, render-target scaling, fullscreen controls, and game logic have
not been ported; the common SDL host covers the maintained scenes.

Benchmarks are organized by workload rather than runtime. Their native
collector diagnostics remain C-specific. R7RS ports can still depend on
C numeric behavior; benchmark acceptance is separate from the portable
library contract.

See docs/portability.md for the shared-code rules and migration details.
