The condition prototype has been integrated into chez/otium/conditions.sls.
Run the maintained cross-runtime suite with:

  python3 shared/tests/test_conditions.py

The experiment established that explicit handler dispatch, dynamic parameters,
escape continuations, and dynamic-wind can implement the Otium protocol on
Chez. Native guard intercepts exceptions too early to implement Otium try
by itself; the implementation dispatches before escaping to catch clauses.

The integration deliberately changed C's incremental handler installation to
install all bindings after their initializers finish. Restart clauses remain
active and may invoke themselves or sibling clauses. C previously exposed
those restarts but failed to handle a second invocation.

The original prototype and its narrow fixture translator were removed in
favor of the shared semantic tests. See chez/NOTES.txt and specs/language.md
for the current contract and the remaining collection/reader differences.
